Approach. One task per screen, primary action pinned to the thumb zone, 56px targets. Deep blue is the only action colour; teal marks Container, violet marks Lori; green/amber/red appear only for count status. Pallet numbers use condensed bold numerals so they read like the physical sticker. Office screens and A4 print layouts are in Tally Sheet Office.
Assumptions. Product master list comes from the server and is cached offline. Worker name comes from login. References are TS-YYMM-####. Sample data is invented for the second item (LAM SOON SHORTENING 16KG, pallet 8 mixed).
